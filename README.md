# Luna AI — Assistente Pessoal para Aprendizado de Inglês

**Luna AI** é um projeto de assistente pessoal desenvolvido em Python, com o objetivo de tornar o aprendizado de inglês mais acessível, interativo e personalizado.

A proposta é criar uma tutora virtual que ajude pessoas iniciantes a desenvolver vocabulário, compreensão escrita, pronúncia e conversação em inglês, incluindo conteúdos específicos para a área de Tecnologia da Informação.

## Objetivo do projeto

Desenvolver uma aplicação desktop com recursos de inteligência artificial, interação por texto e voz e acompanhamento da evolução do estudante.

O projeto também faz parte da minha jornada de aprendizado em programação e desenvolvimento de software.

## Funcionalidades

- [x] Busca de vocabulário em inglês.
- [x] Consulta de definições e exemplos.
- [x] Pronúncia de palavras e frases em inglês.
- [x] Síntese de voz em português e inglês.
- [x] Tradução automática de definições e exemplos para português.
- [ ] Interface desktop interativa.
- [ ] Conversação em inglês por texto.
- [ ] Tutoria personalizada para iniciantes.
- [ ] Exercícios de vocabulário e gramática.
- [ ] Inglês aplicado à Tecnologia da Informação.
- [ ] Reconhecimento de voz.
- [ ] Histórico de conversas.
- [ ] Acompanhamento do progresso do estudante.
- [ ] Funcionamento offline sempre que possível.
